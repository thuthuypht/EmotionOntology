# Important: files intentionally excluded from the public package

The full institutional NTU survey files and fully populated institutional KG were not
included because they contain lecturer identifiers/names and raw free-text comments.

This omission is intentional and protects institutional privacy while preserving
reproducibility of the paper's reported five-seed benchmark experiments.

If a private archival bundle is needed for internal university use, create and store it
separately; do not publish it in the public GitHub repository.
