# GitHub upload guide

Recommended repository name:

`EmotionOntology-CSoNet2026`

Expected public URL:

https://github.com/thuthuypht/EmotionOntology-CSoNet2026

## Recommended workflow

1. Sign in to GitHub as `thuthuypht`.
2. Create a new **Public** repository named `EmotionOntology-CSoNet2026`.
3. Do **not** initialize it with a README, `.gitignore`, or license, because this package
   already provides a README and `.gitignore`.
4. Extract `EmotionOntology_CSoNet2026_GitHub_Public.zip` on your computer.
5. Open the new repository and choose **Add file → Upload files**.
6. Drag the contents of the extracted `EmotionOntology-CSoNet2026` folder into GitHub.
7. Use commit message: `Initial public reproducibility release for CSoNet 2026`.
8. After commit, verify that `README.md`, `code/`, `data/`, `ontology/`, and `results/`
   are visible at the repository root.
9. Confirm the final URL is:
   `https://github.com/thuthuypht/EmotionOntology-CSoNet2026`
10. Do not upload any institutional files listed in `docs/DATA_AVAILABILITY.md`.

If the browser upload struggles with the folder tree, use GitHub Desktop:
**File → Add local repository**, select the extracted folder, then **Publish repository**.
